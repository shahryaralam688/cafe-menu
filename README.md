# CafeMenu

Native SwiftUI iOS cafe ordering app.

- Homepage with Coffees, Pastries, and Cakes
- Circular dial picker with smooth spin and self-rotation
- Sheet navigation between categories, dial, and cart
- Cart with plated photos, grand total, and Make Payment
- Optional AR placement on device

## Requirements

- Xcode 15+
- iOS 17+
- iPhone (portrait)

## Run

1. Open `CafeMenu.xcodeproj` in Xcode
2. Select an iPhone simulator or device
3. Build and run (`Cmd+R`)

## Flow

Categories → dial select → cart wheel → Make Payment
